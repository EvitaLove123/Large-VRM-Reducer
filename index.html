2. Secondary Node

This tool manages the dedicated glTF node named secondary inside a VRM file. It is separate from VRM 0.x Secondary Animation and Spring Bone.

Choose a VRM file to inspect its Secondary Node.

Compatibility & scope

• VRM files only. GLB-to-VRM conversion is not supported.

• Secondary Node means a node named secondary in the VRM's glTF nodes[] hierarchy. It is not secondaryAnimation or Spring Bone.

• If missing, the tool adds it to nodes[] and the active scene's root nodes, following the supplied reference VRM.

• Texture compression, polygon reduction, mesh optimization, and BlendShape removal are not implemented in this build.
