Compatibility & limitations

• VRM 0.x files only. This tool does not convert GLB, PMX, or FBX to VRM.

• This build optimizes embedded textures. It does not yet simplify polygon geometry, compress mesh data, or remove BlendShapes.

• Transparent textures are kept in PNG format. Opaque textures may be converted to JPEG, which can introduce slight visual differences.

• A 100 MB model is not guaranteed to become 50 MB. Results depend on how much of the file size comes from textures.

• Keep your original VRM as a backup and test the exported file in your target app.
